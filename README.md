# Parser Serve

统一的多模态内容解析服务，将 Office 文档、图片、网页、音视频等不同来源的内容转换为结构化、可检索的数据，便于接入知识库、RAG、全文检索、内容审核和数据分析等场景。

> 项目当前处于初始化阶段。仓库已包含基础 Python 项目结构，解析接口、解析器和任务调度等能力仍在建设中。下文中的“规划能力”代表项目目标，并不表示当前版本已经全部实现。

## 项目目标

不同文件类型通常需要各自独立的解析工具和处理流程。Parser Serve 计划通过统一的服务接口屏蔽底层差异，提供：

- 统一输入：支持上传本地文件或提交远程 URL
- 统一输出：返回文本、元数据、内容分块及媒体信息
- 可扩展解析器：按文件类型选择对应的解析策略
- 同步与异步任务：兼顾小文件实时解析和大文件后台处理
- 面向 AI 应用：输出可直接用于检索、向量化和大模型处理的数据

## 规划支持的内容类型

| 类别 | 常见格式或来源 | 主要解析内容 |
| --- | --- | --- |
| Office 文档 | DOC、DOCX、XLS、XLSX、PPT、PPTX | 正文、标题、表格、工作表、幻灯片及文档元数据 |
| 通用文档 | PDF、TXT、Markdown、CSV | 文本、章节、表格、页码及基础元数据 |
| 图像与照片 | JPG、JPEG、PNG、WEBP、TIFF、BMP | OCR 文本、尺寸、EXIF 信息及图像描述 |
| 网页 | HTTP/HTTPS URL、HTML | 标题、正文、链接、页面元数据及主要内容区块 |
| 视频 | MP4、MOV、AVI、MKV、WEBM | 音轨转写、时间戳、关键帧及媒体元数据 |
| 音频 | MP3、WAV、M4A、AAC、FLAC、OGG | 语音转写、时间戳及媒体元数据 |

实际支持范围将以已接入的解析器、运行环境和部署配置为准。

## 统一输出模型

解析结果计划采用统一的数据结构，核心字段包括：

```json
{
  "source": {
    "name": "example.docx",
    "type": "document",
    "mime_type": "application/vnd.openxmlformats-officedocument.wordprocessingml.document"
  },
  "content": {
    "text": "解析后的完整文本",
    "blocks": [
      {
        "type": "paragraph",
        "text": "一个内容区块",
        "metadata": {}
      }
    ]
  },
  "metadata": {
    "title": "示例文档",
    "language": "zh-CN"
  }
}
```

不同类型的内容可以扩展专属字段，例如文档页码、表格坐标、图片尺寸、音视频时长和转写时间戳等。

## 典型应用场景

- 为知识库或 RAG 系统准备结构化语料
- 对企业文档进行全文检索和内容归档
- 批量提取合同、报表和演示文稿中的信息
- 对扫描件、截图和照片执行 OCR
- 抽取网页正文并清理导航、广告等噪声
- 将会议录音、访谈和视频转换为带时间戳的文本

## 快速开始

### 环境要求

- Python 3.13 或更高版本
- 推荐使用 [uv](https://docs.astral.sh/uv/) 管理虚拟环境和依赖

### 本地运行

```bash
git clone <repository-url>
cd parser-serve
uv run main.py
```

当前程序会输出：

```text
Hello from parser-serve!
```

## 计划中的服务能力

后续服务接口计划覆盖以下流程：

1. 提交文件或远程 URL
2. 自动识别 MIME 类型并选择解析器
3. 执行文本提取、OCR、网页清洗或音视频转写
4. 对内容进行标准化和结构化处理
5. 返回解析结果，或通过任务 ID 查询异步任务状态

具体 API 路径、请求参数和鉴权方式将在接口实现后补充。

## 设计原则

- **一致性**：不同输入类型尽可能返回一致的数据结构
- **可追溯**：保留页码、时间戳、来源 URL 等定位信息
- **可扩展**：新增文件类型时无需修改核心业务流程
- **安全性**：限制文件大小、解析时长和外部资源访问范围
- **可观测**：记录任务耗时、解析器状态和失败原因

## 安全建议

解析服务通常需要处理不受信任的文件和 URL。生产环境应至少考虑：

- 校验文件类型、扩展名、MIME 类型和文件大小
- 对解析进程设置 CPU、内存和执行时间限制
- 在隔离环境中处理 Office、PDF 和媒体文件
- 防范压缩炸弹、恶意宏、路径穿越和服务端请求伪造（SSRF）
- 对临时文件设置独立目录、最小权限和定期清理策略
- 避免在日志中记录原始敏感内容
